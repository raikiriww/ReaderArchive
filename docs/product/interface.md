# 界面规则

本文记录当前界面（v0.5.0 起）的行为规则。可交互原型见 [designs/reader](../../designs/reader/README.md)，原型应与本文一致。

## 整体布局

- 左侧是侧栏，右侧是全宽列表。点开一条存档，会在弹出的阅读窗口里阅读，列表留在后面。
- 只有一种布局（侧栏 + 列表 + 弹出阅读窗口）和一种配色（青绿）。

## 侧栏

从上到下：

- **保存网页**：显示快捷键 `N`。
- **搜索**：显示 `⌘K`，点击后聚焦列表顶部的搜索框。
- **未读**：数字是未读存档数加上需要处理的任务数。有需要处理或有问题的任务时，数字显示为橙色。
- **全部存档**。
- **标签**：带筛选框，默认显示使用最多的 10 个，其余可以展开。
- 底部依次是 **订阅源**（打开管理弹窗）、**内置浏览器**（在新标签页打开 `desktop_url`）、**设置**，以及用户菜单（修改密码会进入设置里的「账户安全」，退出登录）。

## 列表

### 未读

- 包含所有未读存档，手动保存和 RSS 都算。
- 最上面是「需要处理」分组：排队中、保存中、等待手动处理、失败的任务，不管是否已读都放在这里。
- 其余按保存时间分组：今天、昨天、本周、本月、更早。

### 全部存档

- 来源筛选：全部来源 / 手动保存 / 订阅。订阅文章只在这里查看，没有单独的订阅视图。
- 状态筛选：全部 / 未读 / 有问题。「有问题」指等待手动处理和失败的任务。

### 标签视图

- 从侧栏点一个标签进入。用「再加一个标签」叠加更多标签，多个标签同时满足才显示。

### 列表行

- 显示标题、正文摘要、来源、时间和标签。
- 摘要会去掉平台套话：微博开头的「公开 / 时间 / 发布于 / 来自 / 已编辑」，以及 `Daily Hacker News for …` 前缀。
- 来源：手动保存显示「手动」，RSS 显示订阅源名称（没有名称时显示「RSS」）。
- 只有网页保存失败（`page_error`）才显示警告。视频下载失败不显示警告。
- 只有确实保存了视频才显示视频图标。

### 打开方式

- 单击：在阅读窗口里打开。
- `⌘`/`Ctrl` 点击、中键点击或 `⇧Enter`：在新标签页打开 `/?read=<id>`，从搜索结果打开时会带上 `&q=`。

## 阅读窗口

### 顶部

顶部有两行，高约 79px。

- 第一行：关闭、上一条/下一条、位置「n / 总数」（当前条目不在列表里时不显示）、标题（点击或按 `R` 改名）、「未读 / 已读」标记、版本菜单（同一规范化网址的其他保存）、原貌/正文切换（`V`）、在新标签页打开、详情（`I`）、「⋯」菜单。
- 「⋯」菜单：改名、标为已读/未读、打开存档文件、复制原网址、重新归档…、删除。还在等待的任务显示为「取消等待并删除」。
- 第二行：来源、保存时间、「原网页」链接、标签编辑（`T`）。标签编辑会补全已有标签，但不推荐标签。

### 原貌

- 网页快照用 `<iframe sandbox="allow-same-origin">` 显示，不运行脚本。文件地址是 `/api/v1/archive-tasks/{id}/files/{file_name}`。
- 不能使用 `result.view_url`，因为访问它会把存档标为已读。
- PDF 用不带 sandbox 的 iframe 显示。只有视频的存档显示 `<video controls>`。
- 焦点在快照里时，按键会转发给应用，所以快捷键仍然有效。

### 正文

- 显示存档里提取的文本。从搜索结果打开时，命中的文字会高亮，并跳到第一处。

### 未完成的任务

- 排队中、保存中：显示步骤进度。
- 等待手动处理：显示处理页面的状态，分为已连接、未打开、已丢失，并提供打开处理页和继续保存的操作。
- 失败：显示原因，可以重新归档或删除。

### 详情抽屉（`I`）

- 提示：yt-dlp 的「没有视频」类报错显示为「此网址不含视频」，不当作错误。
- 文件：打开、下载、改名、删除、上传、刷新。
- 重新归档：可以勾选「保存前手动处理」。
- 任务信息，以及删除存档。

## 已读

- 已读状态只能手动修改：按 `E`、点顶部的「未读 / 已读」标记，或用「⋯」菜单。
- 打开存档不会标为已读。
- 在「未读」里标为已读后，这一条在阅读窗口打开期间会继续留在列表里，关闭窗口后才移走，光标移到下一条。

## 搜索

- 按 `/` 或 `⌘K` 聚焦列表顶部的搜索框，结果直接显示在列表里。
- 筛选：类型、来源、日期、标签、仅未读、只匹配原词、排序。
- 「意思可能相关」的结果默认折叠。
- 记住本次会话里最近的搜索。
- 搜索数据还没建立完时，会提示当前覆盖范围。

## 保存网页

- 入口：按 `N`、点侧栏的「保存网页」，或在输入框以外的任意位置粘贴 http(s) 网址。
- 弹窗会检查网址是否有效，并显示识别出的网站。同一网址已经保存过时，提示「会另存一个新版本」。
- 标签可以不填，不自动预选，也不推荐。
- 可以勾选「保存前手动处理」。按 `⌘↩` 提交。

## 订阅源

- 只在管理弹窗里管理：添加、立即检查、启用/停用开关、删除（需要确认）。

## 设置

- 系统设置：语义检索状态卡片、轮询间隔、RSS 检查间隔。
- 用户管理。
- 账户安全：修改密码。

## 快捷键

| 按键 | 作用 |
|---|---|
| `J` / `K`（或 `↓` / `↑`） | 下一条 / 上一条 |
| `Enter` | 打开 |
| `⇧Enter` | 在新标签页打开 |
| `Esc` | 逐层关闭：菜单、抽屉、阅读窗口 |
| `E` | 标为已读/未读 |
| `T` | 编辑标签 |
| `R` | 改名 |
| `V` | 切换原貌/正文 |
| `I` | 打开/关闭详情 |
| `O` | 打开原网页 |
| `N` | 保存网页 |
| `⌘V` | 粘贴网址并保存 |
| `/` 或 `⌘K` | 搜索 |
| `?` | 查看全部快捷键 |

在输入框里输入时，单键快捷键不生效。

## 不做的内容

- 分栏布局、青绿以外的配色、紧凑密度。
- 推荐标签。原型里的这些开关只用来对比，不代表要实现。
