## 本轮发现的问题

1. 正文链接刷新时，加载期间页面为空；已增加正常搜索/加载展示。
2. 再次提交相同搜索词没有刷新结果；已修复。
3. 异常阅读链接、清除筛选可能遗留阅读状态；已修复。
4. 后台排名靠前的语义答案可能被前端默认折叠；已保留排名靠前的答案，只折叠后续候选。
5. 视频归档中的推荐数据混入正文；已排除非正文节点，并通过 readable-v3 自动更新旧资料。真实副本更新完成，559 篇可读资料全部就绪、0 失败。
6. 无关候选：保留明确缩写/代码标识符的完整词要求，不把首字母大写的普通概念一概当作专名。额外仅在全候选没有原词依据、首轮全低于 -8 且预算可完整覆盖全部所选窗口时进行完整复核，仍低分才排除。预算不足、未完整评分或模型失败均不据此删除。18 个定向正例及真实无关视频复测通过；这不是普适准确率保证。
7. 测试结束清理钩子放在普通测试模块内，未被执行，产生大量临时数据库。已移到 conftest，严格清理本次生成的临时库；完整测试后确认零残留。
