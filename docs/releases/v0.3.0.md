# v0.3.0 — 搜索体验升级

## 本次更新

- 保留顶栏直接保存网页，同时增加独立搜索入口与快捷键。
- 支持按标题、原文、标签、网址或内容大意查找，并按类型、来源、日期、标签和已读状态筛选。
- 结果展示实际原句；可预览、跳转正文匹配位置，并在返回或刷新后保留搜索进度。
- 相同网址的多次保存可集中查看；不同查询参数的网址保持独立。
- 更换中文和跨语言检索模型，结合关键词和候选比较改善答案选择，全部使用 CPU。
- 修复长文尾部遗漏、隐藏推荐数据混入正文，以及模型准备或失败时影响关键词搜索的问题。

## 升级说明

沿用现有 compose 配置，拉取新镜像后重启即可。数据库会自动升级，旧归档在后台整理；准备期间仍可搜索已有可用内容。

镜像内包含两个新模型，新增约 3.5 GB 原始模型权重。请为下载、解压及运行保留足够磁盘和内存；无需独立显卡。完整应用还包含浏览器，内存需求高于单独运行一个模型。

复杂描述的首次搜索仍可能需要等待。本地真实资料验收约 15–20 秒，实际速度取决于设备及文章数量；语义结果提供原句供核对，不生成或保证答案。

## 验证

228 项后端检查、28 项前端检查通过。18 个真实资料定向问题找回正确文章，并检查了无关结果、原文摘录和定位。桌面与手机流程、全新安装真实保存网页、自动整理、搜索及重启检查通过。

定向问题通过不代表任意问法的准确率。完整记录见 [本地发版验收](../release-acceptance-20260905.md)。
