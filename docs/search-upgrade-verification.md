# 搜索改造交付验收

> 历史阶段记录，包含当时的方案、结果和未完成项。当前实现及最终验收以 [CPU 搜索升级](search-cpu-upgrade.md) 和 [发版验收](release-acceptance-20260905.md) 为准。

2026-09-05。已将确认的搜索设计接入实际应用。以下验证使用独立数据库、合成文章和本地模型；日常使用的 38165 服务及真实资料库未切换。本地验收应用为 http://127.0.0.1:38167/ 。

## 完成标准与结果

| 完成标准 | 实际验证结果 |
| --- | --- |
| 保留直接保存网页的便利，同时提供独立搜索入口 | 顶栏保留 URL 输入和保存按钮；搜索中实际提交保存请求成功，搜索条件和结果保持。Cmd/Ctrl+K 可聚焦搜索。 |
| 搜索结果提供判断依据，并能继续阅读 | 实际搜索长文末尾“帝企鹅育雏”，列表和预览均显示原句；阅读跳至实际命中文字。修复了原句被摘要裁切、长段落只滚到段落中部的问题。 |
| 返回和刷新不丢失搜索进度 | 浏览器返回恢复查询和选中项；刷新保留筛选、页码及阅读状态；阅读返回前后列表滚动位置一致。 |
| 筛选、分页与重复保存可用 | 核验无结果提示、第二页及刷新；21 篇未读中读完第二页最后一篇后自动回到有效页；同 URL 两个版本合为一条，版本链接可打开实际文件列表。 |
| 手机布局和主要操作可用 | 390×844 下无横向溢出，保存、搜索、预览、阅读、返回均实际操作；桌面布局亦已目视检查。 |
| 失败可理解、恢复后可继续 | 短暂停止独立服务，页面显示“无法连接服务器，请检查网络后重试。”；恢复服务后点击重试，保留查询并恢复搜索。 |
| 模型故障不使关键词搜索失效 | 后端专项验证冷启动、忙碌、失败及自动恢复；完整正文准备独立于模型处理。 |
| 质量提升有可复核依据 | 同一批 34 篇合成文章、31 问与旧代码比较；保留原报告和全部失败。详见下方质量记录。 |

## 交付边界

这次修复正文遗漏、关键词依赖模型、错误混合排名和缺少原文依据，并落地完整搜索交互。默认模型经过候选对照后保留。小型开发资料上首条有用比例从 85.2% 升到 100%，但严格整题通过仍为 16/31，另有 15 题存在弱相关候选等问题。页面将不确定内容标为“意思可能相关”；这些失败没有被当作质量达标。

本地浏览器保存检查验证的是请求被接受和搜索状态不丢失；该宿主验收服务没有完整网页抓取工具，不能把它说成已验证外部网页抓取成功。既有归档逻辑通过后端回归；正式镜像未在本次更新或发布。

现有 compose 不需要新增配置才能启用此次应用默认行为。首次更新应用会后台补齐旧存档正文和搜索内容；覆盖不足时页面有说明。真实资料质量、目标设备上的大量文章及并发表现，仍须在正式使用中继续验证。
