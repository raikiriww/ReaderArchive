# CPU 搜索升级验收记录

日期：2026-09-05。当前改动已接入本地验证副本，尚未部署到局域网正式服务。

## 改动及原因

- 默认使用 Qwen3-Embedding-0.6B，输出 384 维向量。按句子和实际模型长度拆分文章，保存完整来源位置，避免旧方案只覆盖开头或截掉答案。
- 保留标题、精确短语和技术名词的直接搜索；正文使用中文分词和 BM25L，与语义候选合并。替换向量模型不能代替关键词搜索：本次资料中 NATS、引号内原句仍依赖关键词通道。
- 使用 BGE-reranker-v2-m3 比较候选与问题；先判断文章，再选能回答问题的原文。完整检查首个语义窗口的各段，避免只检查第一段；问题和紧随的回答一起保留，摘录不跨原文段落或继续填入下一节标题。
- 摘录使用原文位置定位正文，避免重复句子指向错误位置。增加重复查询缓存、模型忙碌或出错时的回退；模型初始化串行执行，避免并发首次加载导致导入失败。

## 默认运行方式

两个模型均使用 CPU。x86 且运行库支持时，BGE 自动采用 INT8；其他架构默认 FP32。线程默认 4，可覆盖。模型随镜像准备，运行时从本地加载；旧 MiniLM 显式配置仍支持。

默认值位于应用及镜像中，无需靠增加 compose 配置才能启用。首次升级需要重新整理文章的语义索引；旧索引按模型和版本区分，不混用。镜像新增两个模型，原始权重合计约 3.5 GB，因此下载和磁盘占用会增加。

## 验证范围

本地使用此前获授权复制的真实资料：560 条记录，其中 559 篇可读，生成新版 1841 个片段；另外一篇没有可提取正文。资料未用于外部模型接口。

18 条根据资料构造的定向问题检查了文章名次、原文证据、摘录以及正文定位；均命中首位。它们不是独立盲测，不能换算成真实用户准确率。最终运行记录见本地 `.local_verify/server-copy-20260905/next-stage-results.json`。

最终完整后端检查通过 205 项，另有 3 条既有依赖及子进程清理警告。代码规范与 38 个应用文件的类型检查通过。浏览器检查覆盖搜索、结果预览、打开正文及定位，已确认收费答案高亮不包含下一节内容。

在本机 M1 Pro / 32 GB 上，自然语言问题首次搜索约 15–20 秒；这仍有明显等待。直接标题、原句搜索通常不到一秒，技术词快速路径验证中预热后的两个问题约 0.4 秒，首次中文索引初始化约 2.3 秒。重复查询有缓存，不应将缓存速度当作首次搜索速度。

在局域网 Ryzen 5 7640HS / 约 60 GiB 内存服务器上，隔离临时环境的公开模型与合成输入测试：同样 32 对、平均 291 个 token，BGE FP32 约 19.3 秒，INT8 约 5.34 秒，约快 3.6 倍；该测试峰值内存约 5.51 GiB。此结果仅代表这批排序输入，不代表完整搜索接口耗时或两个模型同时运行的总内存。

较小 BGE 模型虽更快，但未通过真实答案摘录检查，未选用。
